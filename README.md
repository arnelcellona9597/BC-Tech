# BC Tech website

Marketing site for BC Tech (web design + development, Davao City, Philippines).

- Static HTML, CSS and vanilla JS. PHP is used only to send form emails over SMTP.
- Source lives in `src/`; `npm run build` writes the deployable site to `public/`.
- Brand assets (logo, favicons, social kit) are in `brand/`.

See `docs/` for deployment and setup notes.
